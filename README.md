# HA-DiPO

Project page for **HA-DiPO: Sequential Diffusion Policy Optimization for Heterogeneous Cooperative Transport**.

This static project page presents HA-DiPO, manuscript Figures 1 and 2, and eight freshly recorded MuJoCo Sim2Sim demonstrations. B2 + B2W has five 8-second motion clips (forward, backward, left turn, right turn, and lateral), a 9-second backward payload-perturbation clip, and a 35-second continuous multi-command rollout. B2 + B2 has one 40-second continuous multi-command rollout. The homepage features a 3:31 real-robot cooperative-transport video. Five separate Sim2Real clips cover straight-line transport and turning with and without an added payload, plus human-robot collaboration. The videos retain the source edit, playback-speed labels, payload annotation, and original soundtrack. Paper, arXiv, and code links are forthcoming.

## GitHub Pages

When ready for public release, select **Settings → Pages → Deploy from a branch → main → / (root)**. The entry point is `index.html`; all assets use relative paths so the page works under a repository subdirectory.

No custom domain or build dependencies are required. The page retains a `noindex` directive; this does not make a published page private.
